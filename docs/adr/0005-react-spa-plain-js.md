# React SPA frontend (plain JavaScript, hand-rolled styles)

The M4 frontend is a **React 18 single-page app** built with Vite, written in **plain JavaScript** (no TypeScript), styled with **hand-rolled CSS design tokens** (no component library), talking to the backend over fetch and to chat/notifications over the existing WebSocket + SSE endpoints. The working notes originally templated a Vue 3 SPA; React was chosen deliberately at M4 kick-off (user decision), and nothing in the backend changes — the API, WS protocol (`?token=` handshake), and SSE stream (`?token=` fallback, since browser `EventSource` cannot set headers) are already frontend-ready. We accept React's larger learning surface and the churn of the fast-moving React ecosystem in exchange for the user's familiarity and its ecosystem; alternatives rejected: Vue 3 (the original template line — equivalent capability, not the user's preference) and server-side rendering (unnecessary for an authenticated ops tool). State is deliberately boring: one `auth` store (token pair in `localStorage`, transparent refresh-on-401), one `appError` store (the backend's `{"error": {code, message}}` envelope rendered uniformly), one `notifications` store (SSE connection + toast queue); routing uses React Router with role-aware guards. The dev server proxies to the backend so the browser sees a same-origin API in development, while `CORS_ORIGINS` on the backend remains the production mechanism (already whitelists the Vite port).
